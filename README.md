# Train-Schedule-Analysis
comprehensive Python-based Train Schedule Analysis project that performs data cleaning, pre-processing, exploratory data analysis (EDA), visualization, pivot table analysis, and an interactive route enquiry system using Pandas, Matplotlib, and Seaborn.

# 🚆 Train Schedule Analysis and Interactive Route Enquiry System

## Overview

This project performs end-to-end data analysis on railway schedule data using Python and Pandas.

It includes:
- Data exploration
- Data preprocessing
- Data cleaning
- Exploratory Data Analysis
- Data visualization
- Pivot table analysis
- Interactive train enquiry system

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features

### Level 1
- Dataset overview
- Train source and destination listing
- Number of stops
- Maximum and minimum stop trains

### Level 2
- Standardize schedule fields
- Calculate journey duration
- Route classification
- Station frequency

### Level 3
- Handle missing values
- Remove duplicates
- Verify station order
- Save cleaned dataset

### Level 4
- Journey duration analysis
- High traffic stations
- Visualizations
- Key insights

### Level 5
- Pivot tables
- Cross-tab analysis
- Comparative charts
- Advanced insights

### Level 6
- Interactive route enquiry system
- Direct train search
- Journey duration estimation
